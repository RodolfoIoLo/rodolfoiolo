## 13-05 创建 CI 数据装载工具

创建 `server/cmd/ci-seed/main.go`，文件全文：

```go
package main

import (
	"context"
	"fmt"
	"os"
	"time"

	"github.com/jackc/pgx/v5/pgxpool"

	"github.com/<GITHUB_USER>/<REPOSITORY>/server/internal/security"
)

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 15*time.Second)
	defer cancel()
	password := os.Getenv("E2E_ADMIN_PASSWORD")
	if password == "" { panic("E2E_ADMIN_PASSWORD is required") }
	hash, err := security.HashPassword(password)
	if err != nil { panic(err) }
	pool, err := pgxpool.New(ctx, os.Getenv("DATABASE_URL"))
	if err != nil { panic(err) }
	defer pool.Close()
	var userID int64
	err = pool.QueryRow(ctx, `INSERT INTO users(username,password_hash,nickname,email,role)
		VALUES('e2e-admin',$1,'E2E Admin','e2e-admin@example.com','admin')
		ON CONFLICT(username) DO UPDATE SET password_hash=excluded.password_hash RETURNING id`, hash).Scan(&userID)
	if err != nil { panic(err) }
	_, err = pool.Exec(ctx, `INSERT INTO articles(slug,title,summary,content,author_id,status,published_at)
		VALUES('ci-welcome','CI Welcome','A deterministic article for production-shaped builds.','# CI Welcome\n\nBuilt from the real API.',$1,'published',now())
		ON CONFLICT(slug) DO UPDATE SET title=excluded.title,status='published',published_at=now()`, userID)
	if err != nil { panic(err) }
	fmt.Println("CI seed complete")
}
```

这个命令只接受 CI 环境变量，不内置可登录密码。生产镜像不复制 `ci-seed` 二进制。

## 13-07 创建真实全栈 CI

创建 `.github/workflows/release-gates.yml`，文件全文：

```yaml
name: Release gates
on:
  pull_request:
  push:
    branches: [main]
permissions:
  contents: read
concurrency:
  group: release-gates-${{ github.ref }}
  cancel-in-progress: true

jobs:
  full-stack:
    runs-on: ubuntu-24.04
    timeout-minutes: 30
    services:
      postgres:
        image: postgres:16.9-bookworm
        env:
          POSTGRES_DB: personal_site
          POSTGRES_USER: personal_site
          POSTGRES_PASSWORD: ci-database-password
        ports: [5432:5432]
        options: >-
          --health-cmd "pg_isready -U personal_site -d personal_site"
          --health-interval 5s --health-timeout 3s --health-retries 20
    env:
      DATABASE_URL: postgres://personal_site:ci-database-password@127.0.0.1:5432/personal_site?sslmode=disable
      E2E_ADMIN_USERNAME: e2e-admin
      E2E_ADMIN_PASSWORD: ci-${{ github.run_id }}-Change9
      CONTENT_API_BASE_URL: http://127.0.0.1:8080/api/v1
      NEXT_PUBLIC_API_BASE_URL: http://127.0.0.1:8080/api/v1
      NEXT_PUBLIC_SITE_URL: http://127.0.0.1:3000
    steps:
      - uses: actions/checkout@v5
      - uses: actions/setup-go@v6
        with: { go-version-file: server/go.mod, cache-dependency-path: server/go.sum }
      - uses: actions/setup-node@v5
        with: { node-version-file: .node-version }
      - run: corepack install --global pnpm@11.19.0
      - name: Migrate
        run: docker run --rm --network host -v "$PWD/server/migrations:/migrations:ro" migrate/migrate:v4.19.0 -path=/migrations -database="$DATABASE_URL" up
      - name: Generate ephemeral keys
        working-directory: server
        run: go run ./cmd/keygen -output ../secrets
      - name: Seed deterministic data
        working-directory: server
        run: go run ./cmd/ci-seed
      - name: Test and start API
        working-directory: server
        env:
          APP_ENV: test
          HTTP_ADDRESS: :8080
          PUBLIC_SITE_URL: http://127.0.0.1:3000
          ALLOWED_ORIGINS: http://127.0.0.1:3000
          JWT_PRIVATE_KEY_FILE: ../secrets/jwt_private_key.pem
          JWT_PUBLIC_KEY_FILE: ../secrets/jwt_public_key.pem
          VISITOR_SECRET_FILE: ../secrets/visitor_secret.txt
          UPLOAD_ROOT: ../uploads
          MEDIA_PUBLIC_URL: http://127.0.0.1:8080/uploads
        run: |
          go test -race ./...
          go vet ./...
          go run ./cmd/api > ../api.log 2>&1 &
          echo $! > ../api.pid
          for attempt in {1..30}; do curl --fail http://127.0.0.1:8080/readyz && break; sleep 1; done
          curl --fail http://127.0.0.1:8080/readyz
      - name: Build static application
        run: |
          pnpm install --frozen-lockfile
          pnpm --dir web lint
          pnpm --dir web typecheck
          pnpm --dir web test
          pnpm --dir web build
          pnpm --dir web exec serve out --listen 3000 > ../web.log 2>&1 &
          for attempt in {1..30}; do curl --fail http://127.0.0.1:3000 && break; sleep 1; done
      - name: Browser tests
        run: |
          pnpm --dir web exec playwright install --with-deps chromium
          pnpm --dir web exec playwright test
      - name: Lighthouse budgets
        run: pnpm --dir web exec lhci autorun --config=./lighthouserc.json
      - name: Verify exported content
        run: |
          grep -q 'CI Welcome' web/out/articles/ci-welcome/index.html
          test -s web/out/rss.xml
          test -s web/out/sitemap.xml
      - if: always()
        uses: actions/upload-artifact@v4
        with:
          name: release-gate-evidence
          path: |
            web/test-results
            api.log
            web.log
          retention-days: 14

  supply-chain:
    runs-on: ubuntu-24.04
    permissions:
      contents: read
      security-events: write
    steps:
      - uses: actions/checkout@v5
        with: { fetch-depth: 0 }
      - uses: gitleaks/gitleaks-action@v2
      - uses: actions/setup-go@v6
        with: { go-version-file: server/go.mod }
      - name: Install govulncheck
        run: go install golang.org/x/vuln/cmd/govulncheck@latest
      - name: Scan Go call paths
        working-directory: server
        run: govulncheck ./...
      - uses: actions/setup-node@v5
        with: { node-version-file: .node-version }
      - run: corepack install --global pnpm@11.19.0
      - run: pnpm install --frozen-lockfile
      - run: pnpm audit --audit-level high
```

`@latest` 只用于本机审计工具，不进入构建；记录实际 `govulncheck -version`。若漏洞只存在不可达标准库路径，PR 中附 govulncheck 调用链证据，不能直接忽略。
