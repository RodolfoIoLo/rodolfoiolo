# 事故响应手册

## 分级

- SEV-1：整体不可用、数据泄露或不可逆数据损坏，立即响应并冻结非必要变更；
- SEV-2：API、后台或互动不可用但静态正文可读，30 分钟内响应；
- SEV-3：局部低风险错误，进入正常修复队列。

## 固定流程

1. 确认外部影响并记录 UTC 开始时间；
2. 用回滚、关闭写入口或维护状态止血；
3. 保存容器状态、release、镜像、迁移版本和脱敏日志；
4. 从受保护分支走修复 PR，运行外部 smoke；
5. 恢复后观察 30 分钟，并在 48 小时内完成无责复盘。

疑似泄露时先吊销并轮换 RAM AccessKey、GitHub Secret、JWT 密钥和管理员会话。严禁在聊天、Issue 或日志中粘贴生产环境、Authorization、Cookie、私钥、AccessKey 或完整数据库 URL。
