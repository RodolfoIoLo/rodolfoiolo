# 产品与视觉基线

## 产品目标

这是 Rodolfo Iolo 的个人技术网站，也是一次从需求、契约、实现、测试到生产运维的完整工程训练。目标访客是同学、工程师、招聘者和潜在协作者；他们应在首屏识别作者，在两次点击内找到项目或文章，并能验证项目的技术深度。

## 内容边界

公共站点包含首页、文章列表与详情、项目列表与详情、归档、关于、RSS、Sitemap、评论和点赞。后台包含登录、概览、文章、项目、分类、标签、评论审核、媒体和站点设置。v1.0 不包含用户注册、付费、即时聊天、多租户、微服务或 Kubernetes。

## 信息架构

- 首页：姓名与身份、代表性项目、最新文章、真实统计；
- 文章：按发布时间、分类和标签组织，详情保留 Markdown 语义和结构化数据；
- 项目：问题、约束、技术方案、结果和复盘，不只展示截图；
- 关于：学习经历、工程取向、联系方式和社交链接；
- 后台：以高频内容操作为中心，固定导航、明确状态、可恢复会话。

## 视觉方向

公共站点使用五幕真实风景作为全视口背景：清晨山谷、林间溪流、高山湖泊、云海日落和星空营地。场景随页面滚动交叉淡入，并有低幅 Ken Burns 运动。内容表面采用可读的玻璃材质，圆角不超过 8px，不使用装饰球体、营销式大卡片、SVG 风景或单一紫蓝/米黄/深蓝调色。

姓名 `Rodolfo Iolo` 必须是首页首屏主信号；首屏高度保留下一节提示。公共内容强调自然、清晰和空间感；后台强调安静、紧凑、可扫描，不加载背景大图。

## 色彩与材质

- 基础浅色：纸张绿白 `#f5f7f2`、墨色 `#18201d`；
- 基础深色：炭绿 `#111714`、浅字 `#eff4ef`；
- 功能强调：苔绿 `#2f6b4f`、天空蓝 `#397b9c`、珊瑚 `#c75b4a`；
- 玻璃面板必须有实体半透明底、1px 边界和 14-18px 模糊，不能只靠图片暗部维持对比；
- 阴影只表达层级，不制造漂浮装饰。

## 排版与组件

正文优先系统中文无衬线，展示标题使用 Space Grotesk 回退链，代码使用 JetBrains Mono 回退链。字距固定为 0，不按视口宽度连续缩放字体。按钮用清晰命令文字与 Lucide 图标；纯工具动作优先熟悉图标和 tooltip。模式使用分段控件，二元设置使用 checkbox/toggle，数字使用原生数字输入或 slider。

卡片只用于文章、项目、统计和真实工具；卡片内不再嵌套卡片。固定棋盘、工具栏、图片和媒体必须用明确尺寸、`aspect-ratio` 或网格轨道避免布局偏移。

## 动效与降级

桌面细指针设备可以启用 Lenis 平滑滚动、五幕淡入和 24 秒低幅背景运动。触摸设备使用原生滚动并关闭背景缩放。`prefers-reduced-motion: reduce` 只显示静止第一幕，所有交互仍可完成。动效不能改变内容顺序、阻止键盘导航或成为理解信息的唯一方式。

## 响应式与可访问性

基准视口为 375x812、768x1024、1440x900 和 1920x1080。所有视口不得出现非预期横向滚动、文字遮挡或按钮内容溢出。正文和控件满足 WCAG 2.2 AA；焦点环清晰；图片有合适替代文本，纯背景图片为空 alt；表单错误使用可感知文本，不只改变颜色。

## 素材治理

背景、封面和截图必须记录来源、许可/模型条款、作者或模型版本、生成/拍摄日期、处理命令和最终 SHA-256。原始素材与编辑工程放在加密备份，最终 AVIF/WebP 进入仓库。未完成登记、含水印、人物隐私或权利不明的素材禁止发布。

## 性能预算

十个响应式背景成品合计不超过 2.5 MB，第一幕桌面 AVIF 不超过 300 KB。生产目标：LCP <= 2.5s、CLS <= 0.1、TBT <= 300ms、Lighthouse Performance >= 85、Accessibility/Best Practices/SEO >= 95。静态正文即使 JavaScript 或互动 API 失败仍可阅读。

## 验收权威

具体文件、命令和代码以 `docs/taskbook/` 的时间顺序任务书为准；HTTP 字段和状态以 `docs/api/openapi.yaml` 为准。任何视觉改变都必须同时通过桌面、移动、深色、键盘和减少动效检查。
